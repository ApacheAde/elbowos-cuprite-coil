# Cuprite Coil

Full-colour Python 3 neon three-rail helix arcade for [ElbowOS](https://x.com/ElbowOS).

Ride a copper lodestone down three waving foundry coils.
Catch gold ore. Dodge violet slag. A / D switch rails. R reset.

## Play

```
pip install -r requirements.txt
python3 cuprite_coil.py --play
```

## Record a 9:16 reel

```
python3 cuprite_coil.py --record
```
